# ATM Management System

A Java-based ATM Management System developed using the Spring Framework. 
The project demonstrates Spring Core, Spring ORM, Spring MVC and database integration.

## Technologies Used

- Java
- Spring Core
- Spring MVC
- Spring ORM
- Hibernate
- Maven
- MySQL
- JSP
- Bootstrap

## Features

- User Registration
- User Login
- ATM Service Management
- Database Integration
- CRUD Operations
- Error Handling
- Toast/Dialog based user messages
- Spring MVC request handling
- ORM based database operations

## Spring Concepts Used

- Dependency Injection
- Spring Configuration
- Spring MVC
- Spring ORM
- Hibernate
- SessionFactory
- DAO and Service Layer
- Transaction Management

## Project Structure

The project follows a layered architecture:

- Controller Layer
- Service Layer
- DAO Layer
- Entity/Model Layer
- Configuration Layer
- View Layer

## How to Run

1. Clone the repository.
2. Import the project into Eclipse/IntelliJ IDEA.
3. Configure MySQL database.
4. Update database credentials in the project configuration.
5. Run the application using the configured server.
6. Open the application in the browser.

## Purpose

This project was developed to practice and demonstrate backend development using Java and the Spring Framework, including MVC architecture, ORM-based database interaction and dependency injection.
